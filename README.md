# GearAI Japan

GearAI Japan is a mobile-first web app for Japanese hiking and camping users to manage gear, understand pack weight, and receive AI-powered equipment recommendations.

## Tech Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase Auth and Postgres
- OpenAI API

## Phase 1 Scope

- User auth
- User gear management
- Dashboard weight and value summary
- AI recommendations
- AI recommendation history
- Existing gear vs missing gear analysis
- Pack Lists

Phase 1 does not include a public gear database, PDF export, native apps, maps, GPS, community, or share links.

## Getting Started

Install dependencies, copy `.env.example` to `.env.local`, fill in Supabase and OpenAI values, then run the development server.

```bash
npm install
npm run dev
```
