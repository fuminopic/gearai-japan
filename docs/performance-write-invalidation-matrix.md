# 写入操作与页面失效矩阵

本表用于性能优化时确认 `revalidatePath` 的最小范围。它不改变认证、动态山岳安全状态、Service Worker 或用户页面缓存策略。

| 写入操作 | 改变的事实 | 必须失效的页面 | 本轮结论 |
| --- | --- | --- | --- |
| 新建ギア | `user_gear` 新记录；尚未加入 pack | 首页、マイギア、山行计划、マイパック选择 | 不失效マイパック正文；新记录不改变既有 pack 内容 |
| 编辑/删除ギア | `user_gear` 字段或记录；删除可能级联移出 pack | 首页、マイギア、山行计划、マイパック、マイパック选择 | 全部保留 |
| 更新ギア照片 | 私有图片路径 | 首页、マイギア、详情、マイパック | 全部保留；详情本地预览后不再额外 refresh |
| 加入/移出マイパック | `user_pack_items` | 首页、マイパック、マイパック选择、山行计划 | 全部保留；マイパック移除采用乐观更新，不再重复 refresh |
| 新建/编辑/删除山行计划 | `trip_plans`，包括水・食料重量 | 首页、山行计划、マイパック | 全部保留；日期编辑本地 state 已更新，不再重复 refresh |
| 推荐履历删除 | `ai_recommendations` | 推荐履历 | 维持 action 的 redirect/revalidate；不纳入装备与计划路径 |

认证、当前山岳安全状态、用户 HTML/RSC 缓存和 Supabase 私有签名图片缓存不在本矩阵的可优化范围内。
