# No-image gear todo

This directory is the current source of truth for gear records that still have no image.

- `_todo-active-catalog-no-image.csv`: active catalog items visible in the app that have no image.
- `_todo-all-gear-products-no-image.csv`: all `gear_products` records that have no image, including inactive/hidden records.
- `_todo-user-gear-no-image.csv`: user gear records from the audit snapshot that have no image.
- `by-brand/*/_todo.csv`: active catalog no-image items split by brand.
